# VELORA — Luxury Watch Store

A premium React/Vite concept website for a modern luxury watch brand.

## Features
- Dark / Light theme with localStorage persistence
- Responsive navbar and mobile menu
- Hero landing section
- Watch collection cards
- Add-to-cart interaction with cart count
- Persistent cart state with quantity controls and order summary
- Responsive checkout flow with card and UPI demo payment methods
- Collection section
- About section
- Responsive layout for desktop, tablet and mobile

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
